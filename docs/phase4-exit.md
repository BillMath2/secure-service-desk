## Limits and next phase

The collector is a separate authenticated service with protected append-only tables, but shares the trusted PostgreSQL instance. The synthetic directory and outbox commit atomically; a real external directory would require additional distributed-effect handling. This lab's tmpfs database deliberately loses data when its database container is stopped/recreated. Collector and application restarts preserve the database outbox; host/storage disaster durability is not claimed.

The authorization epoch conservatively invalidates proposals after unrelated protected fixture changes. Stale previews and approvals must be recreated. Standard proposals require both valid, distinct manager and owner relationships even though one approval suffices. Model proposals use fixed server text rather than generated justifications. Human-entered text remains untrusted and screened under the existing fingerprint/canary limits.

IPv4 network denial has live reachable controls; IPv6 denial is inspected in inet policies only. Host, Docker, identity and database administrators remain trusted. The small model sample is functional evidence, not a statistical resistance claim. Phase 5 retains repeated baseline-versus-hardened evaluation, broader attack coverage, clean-checkout reproduction and the recorded demonstration.
